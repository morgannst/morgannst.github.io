📌 บทคัดย่อ (Abstract)

แกน MGBAMicrobiota-Gut-Brain Axis
แกนสื่อสารสองทิศทางระหว่างจุลินทรีย์ในลำไส้-ลำไส้-สมอง ผ่านระบบประสาท ฮอร์โมน ภูมิคุ้มกัน และเมตาบอไลต์ อธิบายถึงเส้นทางการสื่อสารแบบสองทิศทางที่ช่วยให้จุลินทรีย์ในลำไส้มีอิทธิพลต่อการทำงานของระบบประสาท การรู้คิด และพฤติกรรม

🐾 สำหรับเจ้าของ: ลำไส้และสมองของสุนัขเชื่อมโยงกัน สุขภาพลำไส้ส่งผลต่อพฤติกรรมและ vice versa

🎯 ประเด็นสำคัญ

มีการศึกษาบทบาทของ MGBA ในสุนัขที่มี โรคทางพฤติกรรม, โรคลมชักไม่ทราบสาเหตุ (IE), และกลุ่มอาการสมองเสื่อมในสุนัข (CCDS)

Dysbiosisภาวะไม่สมดุลของจุลินทรีย์ในลำไส้ - ความหลากหลายลดลง แบคทีเรียดีลดลง เชื้อโรคเพิ่มขึ้น รบกวนการทำงานของ MGBA ทำให้เกิดการอักเสบของระบบประสาท

ธรรมชาติแบบสองทิศทางหมายความว่า การรักษาที่ลำไส้ อาจช่วยรักษาโรคทางพฤติกรรมและระบบประสาทได้

ผลลัพธ์ที่ดีที่สุดเกิดขึ้นเมื่อ รักษาจุลินทรีย์ในลำไส้และสุขภาพจิตพร้อมกัน

  • • การส่งสัญญาณภูมิคุ้มกันผิดปกติ (Dysregulated immune signaling)

🩺 โรคที่เกี่ยวข้องกับ MGBA

สุนัขที่มีโรคทางพฤติกรรม, CCDS และ/หรือ IE มักถูกการุณยฆาตเนื่องจากคุณภาพชีวิตที่ไม่ดี

📊 ตารางที่ 1: โรคที่เกี่ยวข้องกับ MGBA

โรคที่เกี่ยวข้อง อายุขัยเฉลี่ย สาเหตุหลักของการเสียชีวิต ผลลัพธ์หลังการรักษา ปัจจัยพยากรณ์โรคที่ไม่ดี
โรคลมชักไม่ทราบสาเหตุ (IE) ~5.5 ปี หลัง episode แรก การการุณยฆาต (52% เกี่ยวข้องกับลมชัก) ~40% ปลอดชัก; 64.5% ลดลง ≥50% Cluster seizures, status epilepticus, เพศผู้ทำหมัน
โรคทางพฤติกรรม แปรผัน; ต้องรักษาตลอดชีวิต การการุณยฆาตหรือการปล่อยทิ้ง ส่วนใหญ่ดีขึ้น; ไม่มีรายใด "หายขาด" ความก้าวร้าวต่อมนุษย์, การรักษาล่าช้า
CCDS ไม่ทำให้อายุขัยสั้นลง การการุณยฆาตเพื่อคุณภาพชีวิต (ภายใน 2 ปี หากอาการรุนแรง) 77% ดีขึ้นด้วย selegiline ความรุนแรงตอนวินิจฉัย, ไม่ได้รับการรักษาแต่เนิ่นๆ

MGBA = microbiota–gut–brain axis

📊 ตารางที่ 2: โรคแทรกซ้อนที่อาจเกิดขึ้น

โรคหลักและโรคแทรกซ้อน ตัวอย่าง
โรคทางพฤติกรรม
CIE (Chronic Inflammatory Enteropathy) CIE และพฤติกรรมที่เกี่ยวข้องกับการแยกจาก
โรคทางเดินอาหารอื่นๆ กรดไหลย้อนและเลียพื้นผิวมากเกินไป
โรคลมชักไม่ทราบสาเหตุ (IE)
โรคทางพฤติกรรม IE และพฤติกรรมก้าวร้าว
CCDS IE ในสุนัขอายุ 6 ปี ที่มี CCDS ระดับปานกลาง

🔍 สัญญาณพฤติกรรมที่ไม่寻常ของโรคทางเดินอาหาร

🍽️ Pica (กินสิ่งที่ไม่ใช่อาหาร)

อาจเป็นสัญญาณของ gastroenteritis เรื้อรัง

การเลียมากเกินไป

เลียอากาศ, เลียพื้นผิว - 14/19 สุนัขมีความผิดปกติทางเดินอาหาร

🪰 Fly Biting

พฤติกรรมกัดอากาศ - ส่วนใหญ่มีโรคทางเดินอาหารแฝง

⭐ Star Gazing

จ้องมองท้องฟ้า - พบใน Yorkshire terrier ที่มีการไหลย้อน

💊 การรักษาที่เป็นไปได้

การรักษาที่สมอง

  • • Behavior modification
  • • Psychoactive medications
  • • Anticonvulsants (สำหรับ IE)
  • • Selegiline (สำหรับ CCDS)

การรักษาที่ลำไส้

  • • Prebiotics
  • • Probiotics
  • • Synbiotics
  • • Postbiotics
  • • Fecal Microbiota Transplantation (FMT)

📊 ผลการศึกษา FMT ในสุนัข

  • ✅ สุนัข CIE: เจ้าของสังเกตเห็นกิจกรรมเพิ่มขึ้นและคุณภาพชีวิตดีขึ้น
  • ✅ สุนัข IE ดื้อยา 9 ตัว: พฤติกรรมและคุณภาพชีวิตดีขึ้นทั้งหมด, 4 ตัวมี seizure cluster days ลดลง 50%
  • ✅ สุนัขตำรวจ 20 ตัว: FMT ลดอัตราท้องเสียและตัวบ่งชี้ความเครียด

2️

ใช้แนวทาง Food Allergy Trial

จำกัดอาหารเฉพาะที่เลือก งด treats, chews, supplements อื่นๆ

3️⃣

เปลี่ยนแปลงทีละอย่าง

เปลี่ยนยาหรืออาหารทีละอย่าง เพื่อประเมินผลได้ชัดเจน

4️⃣

บันทึกอาการทางเดินอาหารและพฤติกรรมเป็นตัวเลข เพื่อติดตามแนวโน้ม

5️⃣

เตรียม "Rescue" medications

มียาและแผนโภชนาการสำรองสำหรับเหตุการณ์ไม่คาดฝัน

โปรโตคอลแบบ step-by-step สำหรับการจัดการอาหารในสุนัข MGBA disease

00:00:00

Phase 1: Preparation (Week 0)

เลือก novel protein หรือ hydrolyzed diet
⬜ งด treats, chews, supplements อื่นๆ
⬜ อ่าน label อาหารปัจจุบัน

Phase 2: Elimination (Week 1-8)

⬜ เปลี่ยนอาหาร 100%
⬜ บันทึกอาการทุกวัน
ชั่งน้ำหนักทุกสัปดาห์
⬜ ไม่มีอาหารอื่นเลย

Phase 3: Challenge (Week 9-10)

กลับไปกินอาหารเดิม
⬜ สังเกตอาการ 2 สัปดาห์
⬜ บันทึกการเปลี่ยนแปลง

Phase 4: Re-challenge (Week 11-12)

⬜ กลับไปกิน diet ใหม่
⬜ ยืนยันผล

🧠 DISHAA Assessment Tool

แบบประเมิน Canine Cognitive Dysfunction Syndrome (CCDS)

D = Disorientation, I = Interactions, S = Sleep, H = House soiling, A = Activity, A = Anxiety

1. 🌀 Disorientation (สับสน)

0 - ปกติ
1 - บางครั้งสับสน
2 - บ่อยครั้งที่สับสน
3 - สับสนตลอดเวลา

2. 🤝 Social Interactions

0 - ปกติ
1 - ลดการทักทายบ้าง
2 - หลีกเลี่ยงการปฏิสัมพันธ์
3 - ไม่สนใจเจ้าของเลย

3. 😴 Sleep-Wake Cycles

0 - ปกติ
1 - ตื่นกลางคืนบ้าง
2 - นอนกลางวันมาก ตื่นกลางคืน
3 - สับสนกลางวัน-กลางคืน

4. 🏠 House Soiling

0 - ปกติ
1 - บางครั้งขับถ่ายไม่เป็นที่
2 - บ่อยครั้งที่ขับถ่ายในบ้าน
3 - ขับถ่ายในบ้านเป็นประจำ

5. 🏃 Activity Level

0 - ปกติ
1 - ลดกิจกรรมบ้าง
2 - เดินไร้จุดหมาย
3 - ไม่สนใจสิ่งแวดล้อม

6. 😰 Anxiety

0 - ปกติ
1 - กระวนกระวายบ้าง
2 - เห่าโดยไม่มีสาเหตุ
3 - กลัวสิ่งที่ไม่เคยกลัว
